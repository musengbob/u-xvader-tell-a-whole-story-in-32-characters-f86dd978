A whole tiny story in one Wi-Fi network name — 27 characters, no more:

> My router filed for divorce

The router, personified, has finally had enough of its owner. A situation, a character, and something that happened, in six words.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `output/` locally when run outside the harness). The entry is a single line with no trailing newline.
